## 🎯 Situação Proposta

> **Cenário:** Uma instituição de ensino deseja desenvolver um **Sistema de Controle de Alunos** voltado para o gerenciamento de fluxo de entrada e saída.

### ❓ Questões Orientadoras:
1. **Público-Alvo:** Quem utilizará o sistema?
2. **Requisitos Funcionais:** Cite 3 requisitos funcionais (*o que o sistema deve fazer*).
3. **Requisitos Não-Funcionais:** Cite 2 requisitos não-funcionais (*como o sistema deve operar*).
4. **Validação de Negócio:** Por que é fundamental realizar o levantamento de requisitos antes do desenvolvimento?

---

## 🛠️ Resolução & Especificação

> [!NOTE]
> **Foco do Projeto:** Sistema de Controle de Entrada e Saída de Alunos Matriculados.

### 👥 1. Stakeholders & Usuários do Sistema
* **Diretoria:** Visão estratégica e controle geral da instituição.
* **Coordenação:** Acompanhamento operacional e monitoramento da assiduidade dos alunos.

---

### 📋 2. Requisitos da Solução

| Tipo | ID | Descrição do Requisito |
| :--- | :--- | :--- |
| **Funcional (RF)** | `RF01` | **Cadastro de Alunos:** O sistema deve permitir o registro completo dos alunos matriculados. |
| **Funcional (RF)** | `RF02` | **Consulta de Acesso:** O sistema deve permitir consultar os registros históricos de entrada e saída. |
| **Funcional (RF)** | `RF03` | **Integração de Presença:** O sistema deve associar automaticamente o fluxo de entrada e saída à lista de presença. |
| **Não-Funcional (RNF)** | `RNF01` | **Multiplataforma:** O sistema deve ser compatível e responsivo em múltiplos sistemas e dispositivos. |
| **Não-Funcional (RNF)** | `RNF02` | **Operação Offline:** O sistema deve manter funcionalidades essenciais mesmo sem conexão com a internet. |

---

## 🧠 Justificativa Técnica

> [!IMPORTANT]
> **Por que o Levantamento de Requisitos é Essencial?**
> 
> O levantamento prévio de requisitos previne o **desalinhamento de expectativas** com o cliente, evitando a construção de funcionalidades indesejadas e mitigando o risco de **perda do investimento financeiro** e atrasos na entrega do software.
